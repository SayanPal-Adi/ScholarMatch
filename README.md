# ScholarMatch — Scholarship Eligibility Assistant Prototype

Static frontend prototype for the project brief.

Pages:
- index.html — Home
- login.html — Login
- register.html — Student registration
- profile.html — Student profile
- scholarships.html — All scholarships
- matches.html — Scholarships matching student
- saved.html — Saved scholarships
- applications.html — Application status
- admin.html — Admin dashboard

Open `index.html` in a browser to start.

This is a UI prototype. Login, database storage, real eligibility calculation, authentication, and admin CRUD are simulated and should be implemented in the backend phase.
